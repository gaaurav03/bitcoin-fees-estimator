# Bitcoin Fee Estimator

A small web tool that displays real-time Bitcoin transaction fee recommendations using public mempool data.

## Features
- Live Bitcoin fee estimates
- Multiple confirmation speed options
- Graceful loading and error handling

## Tech Stack
- React
- JavaScript
- Public Bitcoin API (mempool.space)
- Vite

## API Used
https://blockstream.info/api/fee-estimates

## Run Locally
```bash
npm install
npm run dev
